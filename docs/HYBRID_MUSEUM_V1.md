# 오이붕 갤러리 — 하이브리드 장면형 전시관 v1 구현 기록

## 이번 변경
- 기존 Three.js 자유 이동·졸라맨·점프·카메라 오빗 실행을 장면형 탐색으로 교체. 무한 렌더 루프와 Three.js CDN 다운로드가 불필요해짐.
- 정문 → 로비 → 좌측/우측 회랑/특별 전시실 → 작품 정면 → 근접 감상 → 기존 상세 화면.
- PC 방향키(좌우 작품 이동, 위 접근, 아래 복귀), Enter, E(작품 정보), M(전시 지도), F(소등 모드 손전등), 모바일 화면 방향 버튼.
- 기존 DOM 기반 게임 목록을 읽으므로 Supabase에서 추가/수정/삭제된 작품도 회랑과 안내도에 자동 반영. 등록/수정, 후기, 별점, 스크린샷, 플레이 링크는 기존 app.js 및 community.js 기능 유지.
- 실제 썸네일을 별도의 이미지 레이어로 표시, 작품명과 제작자 표시는 HTML 텍스트. 근접 화면에서도 텍스트가 브라우저에서 직접 그려짐.
- 오든링(기사), 퍼리Corp(메이드), 아레나(전투 안내) 등의 SVG 의상을 안내 비서에 사용. 가벼운 호흡 모션과 숨김 버튼. 정식 Live2D 리깅은 아님.
- 라이트/소등 모드 유지, 손전등 마스크, 비상등, 짧은 정전 깜빡임 선택, 기본 꺼짐 환경음. 기존 밝기 설정과 연동.
- WebGL 불필요, 배경은 장면당 고정. CSS 건축 배경은 임시 디자인이며 Blender가 렌더한 실사 배경이 추가되면 우선 사용.

## 오리지널 3D 렌더링 작업 규격

현재 커밋에는 오리지널 Blender 실사 배경 파일이 없습니다. 참고 이미지 URL을 그대로 사이트 배경에 핫링크하지 않습니다. gallery-scene-assets.js에 실제 파일 경로를 등록한 뒤에만 불러옵니다.

| 장면 키 | 카메라 / 건축 구도 | 액자 배치 |
|---|---|---|
| entrance | 정문 중앙, 대칭 광각 | 중앙 입구 |
| lobby | 중앙 로비 정면, 좌우 아치 | 중앙 대표 작품 |
| left | 좌측 회랑의 벽과 원근감 | 중앙 + 인접 2점 |
| right | 우측 회랑, 좌측의 대칭 방향 | 중앙 + 인접 2점 |
| special | 높은 천장, 중앙 큰 벽면 | 특별 작품 |
| focus | 액자 한 점을 바라보는 정면 카메라 | 중앙 큰 작품 |

권장 배경: 16:9 데스크톱 약 2560×1440, 모바일은 별도 9:16 또는 화면 비율에 맞춘 1080×1920. 메인 조명만 바뀐 두 렌더에서 건축, 카메라, 액자 앵커의 픽셀 좌표를 유지합니다. 파일 형식은 AVIF.

예: assets/museum/lobby-light.avif, lobby-dark.avif, lobby-light-mobile.avif, lobby-dark-mobile.avif. 같은 형식으로 6개 장면의 낮/밤을 만듭니다.

작품 이미지, 작품명, 개발자명과 비서는 배경에 합성하지 않습니다. 3D 렌더에서 액자 내용물은 비워 두어 HTML 레이어와 정렬되게 합니다.

파일 업로드 후 gallery-scene-assets.js에서 아래처럼 경로를 등록합니다.

~~~js
window.OIBUNG_SCENE_ASSETS = {
  lobby: {
    light: { desktop: 'assets/museum/lobby-light.avif', mobile: 'assets/museum/lobby-light-mobile.avif' },
    dark: { desktop: 'assets/museum/lobby-dark.avif', mobile: 'assets/museum/lobby-dark-mobile.avif' }
  }
};
~~~
