# 오이붕 월드 — 게임 전체화면 UX

## 목표
브라우저에 접속하자마자 **2D 도트 오이붕 월드 자체만** 보인다. 웹사이트 상단 헤더, 소개 제목, 게시판 탭, 외부 배경, 여백, 문서 스크롤을 제거하고 필요한 기능은 월드 안에서만 연다.

## 화면 구성
- 전체 화면: `#oibung-world-stage`와 Canvas 2D가 `100vw × 100dvh`를 사용. 별도의 페이지 헤더·바깥 카드·큰 소개 섹션 없음.
- 상단 왼쪽: 작은 월드 로고 + 게임 수
- 상단 오른쪽: `☰ 메뉴` 버튼 하나
- 게임 중: 플레이어와 동행 비서, 건물 이름과 입장 팁
- 모바일 하단: 좌우·점프·건물 입장 버튼 (Safe Area 반영)
- PC: 방향키 또는 A/D 이동, Space 점프, E 입장. 조작 버튼 대신 깔끔한 월드 화면.

## 메뉴
월드 화면 위의 인게임 패널에서 기존 기능으로 진입:
- 게임 건물 바로가기 및 건물 목록
- 전체 게임 카드·검색·정렬·찜
- 게임 평가·후기
- 게임 등록
- 밝기 전환

월드로 돌아오기:
- 메뉴 ✕ 또는 Escape
- 게임 목록: 목록 상단의 닫기 또는 Escape
- 후기: 닫기 버튼 또는 Escape
- 건물 상세: 기존 상세 다이얼로그 닫기

## 내부 구조 및 데이터 보존
- `index.html`: 기존 사이트 헤더·탭·게임 카드 영역의 DOM과 ID는 유지하지만 평소 화면에서 숨김. 인게임 메뉴 DOM만 월드 스테이지 안에 배치. 앱의 기존 이벤트 핸들러를 손상시키지 않음.
- `world-fullscreen.css`: 레이아웃·모바일 조작·메뉴·게임목록·후기·상세의 오버레이 스타일.
- `world-fullscreen.js`: 메뉴 열기/닫기 및 기존 DOM 작업 연결. 원래의 `OIBUNG_CATALOG`, `community.js`, 업로드·후기·Supabase 코드 그대로 재사용.
- `oibung-world.js`: 메뉴/목록이 열렸을 때 플레이어 이동을 잠시 중단해 입력 간섭 방지.
- `tests/world-fullscreen.cjs`: PC와 모바일에서 화면 꽉 채움·스크롤 제거·키보드/터치 조작·게임 상세·검색·후기·등록을 확인.

## 주의 사항
게임을 소개하는 기능은 모두 보존해야 함. 오이붕 월드 이외의 추가 게임성이나 공포 기능은 더하지 않음. 기존 데이터, 후기, 썸네일, 계정을 이전하거나 삭제하지 않음.

실기기 iOS/Android의 브라우저 주소창 및 Safe Area는 자동화 테스트와 별도의 마지막 확인 대상.
