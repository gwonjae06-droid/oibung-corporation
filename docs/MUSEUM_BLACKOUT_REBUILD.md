# 전시관 / 소등 후 공포게임 전면 재설계

상태: 설계 확정 대기. 구현·브라우저 검증·배포 완료를 뜻하지 않는다. 기존 HYBRID_MUSEUM_ROADMAP보다 이 문서의 경험 설계를 우선한다.

## 고정 요구사항
- 낮은 우리가 만든 게임을 소개하는 정상적인 전시관이다. 게임별 미니게임 모음으로 바꾸지 않는다.
- 배경은 Blender에서 만든 3D 공간을 고정 시점으로 사전 렌더한다. 자유 이동 WebGL로 되돌리지 않는다.
- 한 회랑에 한 작품. 좌우 이동으로 전체 작품을 순환하고 신규 작품에 자동 대응한다.
- 인간 비서는 KakaoTalk_20261114_191639676.png만 사용한다. 작품별 의상과 임의로 만든 비서는 사용하지 않는다.
- 소등하면 같은 비서가 괴물로 변한다. 인간 원본을 덮어쓰지 않는다. 괴물 자산은 별도 제작·시각 승인 후 연결한다.
- 작품·후기·이미지·권한 관련 데이터와 app.js/community.js의 기존 기능을 보존한다.

## 경험 흐름
1. 정상 관람: 작품, 명패, 비서의 짧은 소개. 작품 클릭으로 바로 상세 열기. 접근/근접 감상 단계 없음.
2. 소등 시작: 공포 연출 안내 후 명시적으로 시작. 기본 음향 OFF, 번쩍임 OFF.
3. 정전: 비서가 옆에서 사라지고 같은 회랑에 비상등과 손전등이 남는다.
4. 탐색: 회랑을 이동하며 비상전원을 찾는다. 괴물은 부재/원거리 실루엣/근접 경고 상태로 변화한다.
5. 위험 규칙: 괴물이 표시된 방향으로 이동하기 전 분명한 경고와 회피 경로를 제공한다. 무작위 즉사는 없다.
6. 복구: 비상전원 조작으로 밝은 전시관과 인간 비서가 돌아온다. 짧은 복귀 대사 후 관람 계속.
7. 언제든 일반 관람 복귀. 실패해도 작품·데이터·관람 기능을 잠그지 않는다.

## 아트 기준
- 괴물은 원본의 흑발·흰 셔츠·검은 조끼·붉은 넥타이 등 인물 정체성을 보존한다.
- 기괴한 관절, 자세, 실루엣과 등장 위치가 중심이다. 색상 반전·필터만 적용한 이미지를 완성 괴물 자산이라고 부르지 않는다.
- 비서는 가까이서 소개받는 크기이되 얼굴·작품·명패·필수 버튼이 동시에 보이도록 구도별 안전 영역을 확보한다.
- 회랑별 변화는 원본 인물과 그림체를 보존한다. 새로운 포즈는 별도 자산 승인 없이 임의 SVG로 대체하지 않는다.

## 구현 구조
- gallery-scene-assets.js는 배경 경로 데이터만 담당한다.
- tools/scene-assets-footer.js의 DOM 감시·자동 클릭·CSS 주입 방식은 제거하고 명시적 상태 전환으로 교체한다.
- 신규 엔진은 catalog/roomIndex/mode/horrorPhase/threatRoom/powerRoom 상태를 관리한다.
- 관람과 공포는 같은 회랑 데이터와 카메라를 공유한다. 회랑 인덱스를 명패 텍스트에서 추출하지 않는다.
- CSS는 전시관 전용 단일 스타일로 관리한다. index.html에서 필요한 리소스를 명시적으로 연결하고 이전 전시관 CSS/JS의 충돌을 정리한다.
- 기존 커뮤니티 대화상자·등록·검색·후기는 별도 유지한다.

## 구현 및 승인 순서
1. 현재 파일·이벤트·CSS 의존성 조사, 커뮤니티 연결 지점 확인.
2. 정상 관람 엔진과 한 작품 한 회랑 구조 교체. 작품 0/1/여러 개, 등록·삭제·검색·정렬 변화 검사.
3. 인간/괴물 아트의 실제 미리보기 승인. 이미지 생성만으로 리깅 완료라고 하지 않는다.
4. 정전/탐색/경고/복구 상태와 안전 복귀 구현. 자동 클릭과 전역 이벤트 가로채기 사용 금지.
5. 키보드·터치·대화상자 초점·모션 감소·오류 내성 회귀 검사.
6. PC 1440x900, 모바일 390x844, 가로 844x390 스크린샷 검수 후 결과 기록.

## 완료 판정
- 커밋 성공, 자동 테스트 성공, 시각 승인, 실제 배포 확인을 구분한다.
- 테스트를 실행하지 않았다면 통과로 기록하지 않는다.
- 원본 비서와 다른 캐릭터로 바뀌지 않는다.
- 회랑에 갇히지 않고 모든 작품과 상세에 접근할 수 있다.
- 공포 중에도 즉시 일반 관람으로 돌아올 수 있다.
- 기존 데이터 손실과 불필요한 실서버 쓰기가 없다.
