# 오이붕 월드 — 2026-11-15 시각·조작·반응형 자체 점검

이번 작업은 새로운 게임성을 추가하지 않고, 게임 소개 월드에서 실제로 눈에 띄는 문제와 조작 결함을 수정하는 것이 목적입니다.

## 확인 및 수정한 문제

| 범주 | 기존 문제 | 이번 조치 |
|---|---|---|
| 캐릭터 미감 | 기존 플레이어는 과도하게 큰 머리와 사각형 몸통이 비서 원화와 어울리지 않았음 | `world-visitor.js`에 신체 비율·눈·머리카락·옷감 명암·팔/다리 걸음을 갖춘 6포즈 투명 도트 캐릭터를 캐시 렌더링 |
| 건물 출입 | 빠른 이동 시 플레이어와 비서가 출입문 한가운데 서서 문을 가림 | 출입문 왼쪽에서 함께 서도록 위치 재조정, 입장 허용 범위와 실제 문 표시 일치 |
| 건물 현판 | 간판이 첨탑과 지붕을 가리고 있었음 | 현판을 입구 윗부분으로 옮기고, 절제된 테두리·배경·글자 크기로 개선 |
| 과장된 말풍선 | 가만히 있어도 같은 대사를 무한 반복하여 미술품을 가림 | 안내는 최초 도착 또는 건물 접근 시 일회성으로만 제공, 일정 시간 후 자동 숨김 |
| 렌더링 깨짐 | 지붕 텍스처 도트가 지붕 실루엣 밖 빈 하늘에 떠 있었음 | 지붕 모양과 동일한 경로로 clip 처리 |
| 입구 가독성 | 거대한 파사드에 비해 문이 너무 작고 캐릭터에 가려져 진입 지점이 불명확했음 | 건물 포털 크기 확대, 도트 입구와 현판을 강조 |
| 구역 전환 | 가까운 건물의 테마에 따라 하늘과 해/달이 갑자기 바뀌었음 | 광장과 인접 건물 사이에서 sky/roof/window 색상을 연속 보간, 해/달 크로스페이드 |
| 클릭 판정 | 건물의 확대한 단순 직사각형 범위 안에 있으면 빈 하늘을 눌러도 워프함 | cached Canvas alpha를 직접 읽어 실제 건물 픽셀 위에서만 선택되도록 수정 |
| 메뉴 조작 | 메뉴 닫은 뒤 포커스가 버튼에 남아 키보드 이동이 불가능할 수 있었음 | 닫기 후 스테이지 포커스 복구; 메뉴 밖 클릭으로 메뉴만 닫고 워프 방지 |
| 상세창 조작 | 게임 상세창을 닫은 후 브라우저가 옛 버튼에 포커스를 돌려 방향키가 먹지 않음 | native dialog의 기본 포커스 복귀가 끝난 다음 프레임에 스테이지 재포커스 |
| 입력 일관성 | 메뉴/소개창이 열려도 터치 이동 키가 남을 가능성 | 비활성 화면에서 이동/점프/입장 차단, 키 상태 및 속도 초기화 |
| 모바일 첫인상 | 세로화면 첫 로딩 시 화면이 하늘만 보이고 첫 게임 건물이 화면 밖에 있었음 | 첫 랜드마크가 화면 안에 보이도록 시작 위치·카메라 계산을 변경하고 리사이즈 시 재중심화 |
| 다크 테마 | 밝기 전환이 HTML만 바뀌고 실제 도트 월드에는 변화가 없었음 | Canvas에 blur 없는 밝기/채도/대비 필터 연결, 버튼 텍스트 동기화 |
| 배경 성능 | 하늘색 계산에 매 프레임 수백 개 행별 색상 변환과 rect 호출 사용 | 한 번의 그라디언트 채우기로 변경, 파랄랙스 레이어는 그대로 유지 |
| 일시정지 | 메뉴/상세창이 열린 동안에도 보이지 않는 2D 씬을 계속 렌더링 | 모달·메뉴가 열리거나 탭이 숨겨질 때 불필요한 장면 렌더링 중지 |
| 메모리 | 큰 건물 Canvas를 25장 이상 캐시해 메모리 사용량이 누적될 수 있었음 | LRU 캐시 상한 10장으로 축소해 오래 보지 않은 건물 이미지 자동 해제 |
| 코드 호환 | 이전 갤러리 동작/애니메이션 스크립트와 카드 가시성이 연결되어 있음 | 삭제 시 회귀를 확인해 해당 스크립트는 보존, 기존 커뮤니티 기능 유지 |

## 기능 보존

- 게임별 건물 테마 및 출입, 바로 이동, 메뉴, 키보드 방향키, 점프
- 모바일 터치 이동·입장
- 전체 게임 검색·정렬·필터와 스크린샷/게임 상세
- Supabase 공유 게임 자동 등록, 후기, 게임 정보 수정
- 기존 PC/모바일 화면 전체 사용 및 여백 없음

## 검증

- Playwright / Chromium: PC 1440×900, 모바일 세로 390×844, 모바일 가로 844×390
- 실질적인 입력 이벤트(CDP touchStart/touchEnd) 사용, 브라우저 팝업 포커스와 실제 Canvas 충돌 테스트
- 모바일 첫 화면에 랜드마크가 보이는지, 클릭 영역이 실제 그림의 alpha와 일치하는지 검증
- 텍스처 캐시 최대 10장 확인을 위해 테스트 내 로컬 게임 13개를 임시 등록, 실제 서버 데이터에는 기록하지 않음
- 기존 전체화면/후기/등록 회귀 테스트도 반복 실행

### 검증 범위 밖

실제 iPhone Safari/Android 제조사 브라우저 실기기 검수, Supabase 쓰기 권한 테스트, 모든 가능한 외부 사용자 콘텐츠 조합은 자동화 검증에서 확인할 수 없습니다. 현재 고밀도 도트 그래픽 자체는 코드 기반 아트로, 수작업 반실사 픽셀 일러스트가 아닙니다.

**원칙:** 새 기능보다 원래 목표인 '친구들 게임을 즐겁고 편리하게 소개하는 월드'의 가독성과 조작감을 우선합니다.
