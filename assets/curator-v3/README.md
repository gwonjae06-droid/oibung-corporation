# 새 도트 비서 / 동일인물 괴물 — v3 아트 패키지

이 폴더에는 사용자가 선택한 **새 캐릭터 디자인 시트**와 그 비서가 변형된 **새 괴물 시트**에서 추출한 두 개의 WEBP 아틀라스를 놓습니다.

| 필요한 파일 | 프레임 배열 (왼쪽→오른쪽) | 정확한 이미지 크기 |
|---|---|---|
| `guide-atlas.webp` | 기본 / 작품 소개 / 설명 / 경계 | 912×408 (228×408 × 4칸) |
| `monster-atlas.webp` | 변이 시작 / 접근 / 공격 / 불길한 대기 | 912×408 (228×408 × 4칸) |

**처리 규칙**
- 배경은 투명하고, 각 인물은 자신의 228×408 셀 안에 들어갑니다.
- 인간 비서와 괴물은 같은 흑발·버건디 리본/넥타이·검은 조끼를 지닌 인물입니다.
- 기존 저해상도 `assets/pixel/`은 업로드와 검증이 끝날 때까지 **긴급 폴백**으로만 남깁니다. 신규 아트 두 개가 존재할 때 새 포즈 및 괴물로 자동 교체합니다.
- 기존 게임 썸네일, HTML 텍스트, Blender 미술관 배경을 도트화하지 않습니다.
- `gallery-scenes.js`는 두 WEBP를 한 번씩 읽고 브라우저 Canvas에서 4칸을 개별 이미지로 자릅니다.
- 원본 비서 시트, 사용자 데이터, 기존 작품 관련 기능은 수정하지 않습니다.

**아트 패키지 설치**
두 WEBP 파일을 이 폴더에 업로드/커밋한 다음 `.github/workflows/curator-v3.yml` 검증을 확인합니다. 검사 통과 전에는 새 이미지를 배포하지 마세요. 이 README나 구형 픽셀 파일만으로는 새 아트가 표시되지 않습니다.

**정확한 상태 기록**: 이 PR의 코드 변경만으로 새 그림이 배포된 것은 아닙니다. 두 바이너리 아틀라스가 저장소에 있어야 합니다.
