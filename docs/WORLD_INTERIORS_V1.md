# 오이붕 월드 — 걸어서 탐험하는 게임별 건물 내부

## 완성 방향
웹사이트 메인 화면은 여전히 **브라우저 전체에 나타나는 2D 도트 횡스크롤 월드**입니다. 사용자가 게임 건물 앞에서 E 또는 모바일 **건물 들어가기**를 누르면 일반 상세 팝업 대신 게임별 분위기의 **실제 횡스크롤 실내**로 진입합니다. 이제 안에서 이동하며 전시물을 찾아볼 수 있습니다.

## 실내 구조
한 실내는 1,850px의 횡스크롤 구역이며 현재 등록된 모든 게임에 같은 인터랙션 구조를 제공합니다.

| 실내 오브젝트 | 위치 | 상호작용 |
|---|---:|---|
| 출구 아치 | x=116 | 원래 서 있던 실외 건물 입구로 돌아감 |
| 메인 포스터 | x=432 | 작품 설명/소개를 인게임 패널에 표시 |
| 전시 기록 | x=792 | 스크린샷·후기·상세 기록을 열 수 있는 패널 |
| 비서 안내 데스크 | x=1148 | 게임 설명과 비서의 안내 내용 표시 |
| 플레이 포털 | x=1530 | 유효한 게임 플레이 URL을 새 탭으로 열기, URL이 없으면 소개 표시 |

**키보드**: 좌우 이동 A/D 또는 방향키, E 상호작용, Space 점프, Escape 실내에서 실외 복귀. **모바일**: 기존 좌우·점프·입장 버튼 그대로 사용. 전시물을 화면에서 탭하면 그 전시물 근처로 접근해 입장 버튼으로 상호작용할 수 있습니다. 사전 동의 없이 게임 링크를 자동 열지 않습니다.

## 테마별 내부 디자인
- **오든링 — 황혼의 왕좌 홀:** 어두운 고딕석·붉은 스테인드글라스·십자 문양 왕좌와 검, 기존 고해상도 성채 일러스트가 걸린 포스터
- **오이붕 아레나 — 황금 콜로세움 로비:** 황금 기둥·청록빛 유리·작은 구체가 도는 경기대
- **오이챔스 — 검격의 회랑:** 푸른 돌기둥·결투 현수막·전시용 검격 문양
- **대학전선 — 작전 지휘 본부:** 녹색 요새 회랑·지도 전시 테이블
- **고양이/퍼리 게임 — 달빛 고양이 저택:** 분홍빛 장식·벨벳 살롱·고양이 조형물
- **그 외 창작물 — 갤러리/연구탑:** 미술관과 천체 모형 등 테마형 일반 실내

천장 골조·샹들리에·촛불, 석재 조각·광선·전시 포스터·아치 창·2층 발코니·장식 조명이 있습니다. 기존 `world-cinematic-art.js`의 오리지널 WebP 석재 질감을 재활용해 외부와 내부의 화풍을 연결합니다.

## 실외 월드 개선
`world-map-details.js`에서 외부 거리의 레이어를 확장했습니다.
- 게임마다 다른 정원과 나무, 입구 양측 조명과 화단
- 건물 사이 휴식 광장의 분수·석재 아치·벤치·빛가루
- 기존 건물의 문·실루엣·실제 물리 지면과 충돌하지 않도록 장식 요소만 추가
- 화면 밖 객체는 건너뛰는 Canvas 컬링, 감속 모션 선호 설정 준수

## 데이터와 기존 기능
- 각 건물은 `OIBUNG_CATALOG.listGames()`에서 자동 생성되며 새 게임 등록 시 **새 내부 공간도 자동으로 생성**됩니다. 별도의 Supabase 테이블이나 마이그레이션은 필요 없습니다.
- 소개 패널은 각 게임의 `title`, `tagline`, `description`, `genre`, `playUrl`를 현재 카탈로그에서 읽습니다. 사용자 입력을 HTML로 삽입하지 않고 `textContent`로 안전하게 표시합니다.
- **전체 작품 소개 보기** 및 **스크린샷·후기 보기** 버튼은 기존 `OIBUNG_CATALOG.openDetail`로 연결되어 과거 데이터/관리기능을 그대로 재사용합니다.
- `playUrl`은 `http:`/`https:`만 허용하고, 새 탭으로 열며 현재 전시실은 그대로 유지됩니다. 없는 링크는 무조건 설명 패널을 엽니다.
- 메뉴에서 빠르게 다른 건물로 이동하면 전시실을 안전하게 종료하고 바깥 건물 앞으로 갑니다. 반대로 출구에서는 입장 전 바깥 위치와 카메라를 복구합니다.
- 각 실내 포스터·안내/포털과 인터랙션 패널의 자세한 내용은 기존 게임 정보와 동기화됩니다.

## 파일 구조
| 파일 | 역할 |
|---|---|
| `world-interiors.js` | 동적 테마 실내 맵·안내/소개/플레이 오브젝트·패널·안전한 링크 |
| `world-interiors.css` | 실내 HUD·소개 패널, 모바일 세로/가로 대응 |
| `world-map-details.js` | 외부 정원·분수·아치·가로등·꽃·휴식 광장 |
| `oibung-world.js` | 기존 조작·카메라·이동·입장/퇴장·전시물 접근 통합 |
| `world-fullscreen.js` | Escape 키로 실내 종료 및 기존 인게임 메뉴 관리 |
| `index.html` | 실내/실외 모듈을 월드 엔진보다 앞에서 로딩 |
| `tests/world-interiors.cjs` | PC/모바일 실내 탐험·자료 연결·출구·후기·카탈로그 테스트 |
| `.github/workflows/world-interiors.yml` | 신규 브라우저 QA와 기존 4개 회귀 테스트 |

## 검증
PC 1440×900, 모바일 세로 390×844, 모바일 가로 844×390에서 실제 Chromium으로 테스트합니다.
전시실 입장→실제 걷기→포스터 E 열기→원본 게임 상세→전시실 복귀→밖으로 나가기→다른 건물 입장→검색·후기까지 확인합니다.
기존 `world-fullscreen`, `world-hd`, `world-cinematic`, `world-polish` 회귀 테스트도 실내 흐름에 맞게 업데이트한 뒤 재실행합니다.

실제 iOS/Android 물리 기기와 Supabase 쓰기 테스트는 별도 검수 항목입니다.
