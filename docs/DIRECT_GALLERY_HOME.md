# 오이붕 갤러리 — 게임이 주인공인 직관형 첫 화면

## 제품 목적
친구들이 만든 게임을 재미있게 소개하고 공유하는 사이트. 전시관 자체를 조작하는 것이 아니라 **게임을 보고 고르고 플레이하고 후기를 남기는 것**이 핵심이다.

## 화면 구조
1. 가벼운 환영 인사와 작은 도트 비서 마스코트. 비서는 작품을 가리지 않고 전투·추적 게임을 요구하지 않는다.
2. 전체 게임을 카드 그리드로 즉시 노출. 썸네일·게임명·장르·개발 상태·짧은 소개·평점/후기·게임 플레이 버튼을 함께 표시한다.
3. 검색, 상태 필터, 정렬을 항상 표시한다. 모바일에서도 별도의 메뉴나 전시장 이동 없이 접근 가능하다.
4. 카드 어디를 눌러도 기존 작품 상세 화면으로 이동. 링크가 있는 게임은 `플레이하기`로 바로 실행 가능하며, 링크 없는 프로젝트는 작품 소개만 보인다.
5. 기존 `평가 · 후기` 게시판과 게임 등록/정보 수정/스크린샷 추가 기능은 그대로 사용한다.

## 변경 및 보존
- `index.html`: 워크스루/공포 회랑 뷰의 HTML과 관련 스크립트 로드를 첫 화면에서 제거하고 `#game-grid`를 직접 노출.
- `direct-gallery.css`: PC 3열, 태블릿 2열, 휴대전화 1열 카드 레이아웃. 기존 미술관 바닥 원근 효과 제거. 이미지와 텍스트를 흐리는 GPU 변환 불필요.
- `direct-gallery.js`: 마스코트 아래 후기 바로 가기를 기존 후기 탭과 연결.
- `app.js`: 게임 카드의 비버튼 영역을 눌러도 기존 상세 화면이 열리도록 개선.
- `gallery-scenes.js` 등 구형 미술관/괴물 로직 **파일 자체는 삭제하지 않음**. 기본 사이트에서는 더 이상 로드하지 않음. 보안·데이터 손실 없이 필요 시 별도 체험으로 복구할 수 있다.
- 게임 데이터, Supabase 연결, 등록/수정/후기·첨부파일 처리 로직은 그대로 유지한다.
- 메뉴의 다크 테마는 공포게임이 아니라 일반 밝기 테마로 재명명한다.

## 검증
- 데스크톱(1440×900), 세로 휴대전화(390×844), 가로 휴대전화(844×390) Chromium 자동 테스트.
- 카드 전체 노출, 카드 클릭 및 상세, 검색/빈 결과, 후기 탭 전환, 플레이 링크, 수평 오버플로, 세로 스크롤, JS 오류 검사.
- 모바일 첫 화면에서 긴 소개가 썸네일을 과도하게 아래로 밀지 않도록 육안 검수.

## 이번 버전의 의도적 제외
- 퓨즈 수집, 괴물 추적, 손전등 게임, 3D 탐험, 실시간 AI 비서 설명.
- 작품별 미니게임이나 추가적인 조작 방법.
- 실제 커뮤니티 DB 쓰기 테스트는 자동 스모크 테스트 대상이 아니므로 배포 후 별도 확인이 필요하다.

**한 문장:** 멋진 전시관을 만드는 대신, 친구들의 게임 자체가 재미있어 보이는 웹사이트를 만든다.
