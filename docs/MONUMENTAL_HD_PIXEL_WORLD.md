# 오이붕 월드 — 기념비적 HD 픽셀아트 개편

## 사용자 요청
전체화면 횡스크롤 소개 월드의 게임 건물들을 훨씬 거대하고 높게 만들고, 벽돌·재질·유리·지붕·조명에 수천 개 단위의 추가 픽셀을 그려 고밀도 픽셀아트로 보이게 함. 비서도 더 예쁘고 선명하게 보이도록 개선.

## 실제 적용
- **기본 렌더링 해상도**: 이전 `LOGICAL_PIXEL_SIZE=2`에서 1로 변경. 같은 브라우저 화면에서 래스터 픽셀 수 약 4배.
- **건물 너비/높이**: 이전 약 177~198 × 174~213 논리 픽셀에서, 테마별 630~730 × 700~850 논리 픽셀로 변경. 화면 높이의 대부분을 차지하게 만들되 세로/가로 화면에 맞춰 스케일을 조정함.
- **건물 간 거리**: 300 → 930 논리 픽셀. 플레이어 이동 속도는 145 → 255로 올려 거대한 세계를 걷는 속도감과 탐색 편의성을 양립.
- **건물 디자인**: 오든링 고딕 성·삼중 첨탑·붉은 스테인드글라스·성벽/부벽; 오이붕 아레나의 거대한 돔과 삼층 로마식 아치·기둥; 오이챔스 무술 도장·겹지붕과 대검 장식; 대학전선 관측탑·깃발·군사 본부; 고양이 테마 저택; 공통 스튜디오·탑 건물.
- **초고밀도 텍스처**: 각 석재마다 독립적인 벽돌 색 차이, 홈·마모·균열·조각 무늬. 유리창의 반사 픽셀, 고딕 아치 석재, 원기둥 하이라이트와 그림자, 금속 장식, 깃발 및 개별 창문 색과 지붕 타일의 촘촘한 패턴.
- **성능**: 무거운 건물 렌더링은 게임별 **Canvas 2D 오프스크린 스프라이트**로 한 번 생성·캐시. 이동할 때는 현재 보이는 건물만 복사하고 반짝임·먼지 입자만 따로 그림. 공유 서버로 등록되는 게임이 많아져도 캐시를 최대 약 26개로 제한.
- **비서**: 이전 15×29 직사각형 캐릭터에서 갤러리가 이미 보유한 선명한 고해상도 비서 `assets/curator-v5/guide-{neutral,present,explain,alert}.webp`를 직접 씀. 걸을 때 도트 보행·바운스, 작품 가까이서는 소개 제스처, 쉬고 있을 때는 호흡 효과. 검은 머리·흰 셔츠·검은 조끼·버건디 넥타이 정체성을 유지.
- **플레이어**: 이전보다 세부 눈·머리카락·의상·장갑·구두 표현을 많이 추가하고, 비서와 대형 건물을 가리지 않도록 크기를 줄임.
- **환경**: 높은 배경 시가지 실루엣, 쌓인 산/구름, 광택 있는 석재 도로, 푸른 하늘과 붉은 달.
- 기존 월드 **건물 입장, 빠른 이동, 등록·수정, 공유 게임 자동 건물 생성, 후기·스크린샷·플레이 링크, 전체화면 UI**는 모두 유지.

## 아키텍처
- `world-hd-architecture.js`: 색상 및 테마별 건축물 픽셀 레이어, 계단·포털·슬레이트 지붕·도트 유리·현수막·석재·그레인 생성, 게임별 캐싱.
- `oibung-world.js`: 새 크기·카메라 스케일, 캐시 렌더러 호출, 고해상도 비서와 세밀해진 플레이어 애니메이션, 상세한 배경/도로 처리.
- `index.html`: 건물 렌더러를 기존 월드보다 먼저 로드하고 캐시 무효화 버전 지정.
- `tests/world-hd.cjs`/Actions: 1440×900, 390×844, 844×390 실제 Chromium 검사.

## 한계 및 QA
- **실제 완전한 반실사 수작업 픽셀아트는 아님.** 원래 단순한 도트보다 크게 복잡해진 코드 기반 고밀도 픽셀아트. 각 건물의 사진 수준 디테일이나 제작자별 전용 커스텀 원화는 별도 아트 패스로 진행할 수 있음.
- **비서의 새 원화 파일을 다시 생성한 것은 아니며**, 이미 저장소에 있는 고해상도 비서 원화를 2D 월드에 실제로 표시하도록 바꾼 것임.
- 가로 모드에서는 건물 전체 높이가 화면 안에 들어오도록 스케일을 자동으로 축소함.
- 자동 성능 테스트는 헤드리스 Chromium 환경의 프레임 페이싱 수치이지 실기기 보장은 아님. 실제 iOS/Android 기기는 별도 검수 필요.
- GitHub Actions 테스트: 월드 해상도, 성·아레나·비서 스프라이트 로드, 기존 작품 입장, 게임 목록·후기, 스크롤 없는 전체화면, 화면 크기별 조작과 캐시/프레임 속도 체크.
