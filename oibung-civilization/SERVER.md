# 오이붕 문명 공유 서버

Node.js 20 이상에서 이 폴더 안에서 `node server.mjs`를 실행하고 http://localhost:8080/ 을 연다. 추가 패키지는 필요 없다. 서로 다른 브라우저는 별도의 성좌로 같은 세계를 관찰한다. 기존 Pages 주소는 개인 모드다.

외부 운영에서는 HTTPS 뒤에 단일 Node 프로세스를 두고 PORT와 영구 디스크의 WORLD_FILE 경로를 지정한다. 저장 파일에는 성좌 세션이 포함되므로 비공개로 보관한다. 서버는 접속자가 없어도 진행하고 정지 중에는 세계 시간이 멈춘다. SIGTERM은 종료 직전 저장한다.

카카오 채널은 KAKAO_SECRET을 긴 임의 값으로 설정하고 채널 관리자에서 HTTPS /kakao/<KAKAO_SECRET>를 스킬 URL로 등록한다. 폴백 또는 명령 블록을 이 스킬에 연결한다. 웹에서 사도를 고른 후 발급한 코드를 5분 내 채널에 보내면 /계시 별 관찰, /역사, 사도 근황을 쓸 수 있다.
