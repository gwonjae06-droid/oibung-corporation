# 오이붕 갤러리 — 하이브리드 도트 B안 (v1)

## 확정 방향
**실사형 전시관 배경 + 도트 비서·괴물 + 선명한 원본 작품 이미지·HTML 글씨.**

- 기존 Blender 미술관 AVIF 배경을 변경하지 않는다.
- 게임 썸네일과 작품 상세 창, 후기·등록·수정 등 커뮤니티 데이터는 변경하지 않는다.
- 사용자 승인 원본 비서(낮게 묶은 흑발, 흰 셔츠, 검은 조끼·바지, 버건디 넥타이)의 4포즈에서 도트 자산을 생성한다.
- 밤의 괴물 역시 동일한 비서의 **중간 변형 실루엣**으로 제작한다. 완전히 별도의 정체 불명 몬스터 이미지를 끼워 넣지 않는다.
- 2D 도트에만 `image-rendering:pixelated`를 적용하고 배경·사용자 그림·HTML 텍스트는 흐리지 않는다.

- 사용자 설정 **일반 관람 복귀**, 손전등, 숨기·기다리기, 비상전원 복구 및 기존 경고 흐름 유지

## 구현 범위와 남은 문제

- 원본 그림에 기반한 다운샘플링·32색 팔레트 제한·알파 보존 방식으로 생성한 **1차 도트 자산**이다. 픽셀아트를 처음부터 손으로 그린 정교한 스프라이트는 아니다.
- 변신은 현재 경계·왜곡·어둠의 **단계형 연출**이다. 프레임마다 정교한 손·얼굴 움직임을 가진 완성형 애니메이션이나 정식 Live2D 리깅이 아니다.
- 괴물 2포즈는 머리카락·복장·넥타이 등 원본 식별 요소를 남긴 신체 변형이다. 괴물의 이동 AI, 충돌 판정, 레벨 수 증가는 이번 작업 범위 밖이다.
- 이미지 크기가 줄면 전송 부담도 줄 수 있지만 기기별 FPS·실데이터 부하·배터리 소모의 정량 측정은 여전히 필요하다.
- CSS `image-rendering:pixelated`는 이미지에만 적용하며 **글씨의 확대/픽셀화는 금지**한다.

## 검증과 배포

Playwright `tests/pixel-hybrid.cjs`는 Chrome 1440×900, 390×844, 844×390에서 다음을 확인한다.

- 비서와 괴물의 생성 이미지 존재 및 실제 로드·도트 렌더링
- 기존 Blender 미술관 배경 URL 보존, 작품 이미지에는 도트 필터 미적용
- 기본/설명/경계/변이 포즈, 일반 관람과 밤 전환, 손전등·복귀
- 괴물 조우 시 해당 PNG 표시, JS 오류, 모바일/데스크톱 화면 잘림
- QA 성공 시에만 GitHub Actions에서 생성된 PNG 7장과 감사 정보를 브랜치에 추가

**검증 후 PR 병합 시에만 `main`에 적용한다.** 제작한 원본 포즈는 삭제하지 않는다.
