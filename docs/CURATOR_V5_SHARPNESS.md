# 오이붕 갤러리 — 비서 도트 선명도 개선 v5

## 목적

이전 v4는 원본 228×408px 셀을 288×512px로 **Lanczos 보간 확대**하고 브라우저에서 `image-rendering: auto`로 표시했습니다. 여기에 회랑마다 ±1° 회전과 가변 비율이 더해져 글자와 미술관 배경은 또렷한데 비서와 괴물 외곽이 흐릿해 보였습니다.

## 이번에 변경한 것

- **새 원화:** 기존 그림을 업스케일하지 않고 새로 제작한 1536×1024px 4열×2행 도트 원화 `assets/curator-v5/curator-atlas.webp`.
- **1:1 아트 추출:** `tools/build_curator_v5.py`가 384×512px 각 칸의 알파를 유지해 잘린 여백만 제거. 새 그림의 픽셀을 재확대/재축소하거나 색을 32색으로 줄이지 않습니다.
- **일반 비서:** 기본·소개·설명·경계의 네 포즈 `assets/curator-v5/guide-*.webp`.
- **괴물:** 같은 복장과 헤어스타일이 보이는 변이·접근·돌진·대기 `assets/curator-v5/monster-*.webp`.
- **변신:** 중간 프레임 `morph-00.webp`~`morph-11.webp` 12장. 기존의 반투명 이미지 겹침 대신 순서 디더링으로 또렷한 픽셀을 유지합니다.
- **표시:** v5 스프라이트에만 `image-rendering: pixelated` 적용. 미세 회전 삭제, CSS에서 픽셀 단위 표시 높이(데스크톱 약 630px, 모바일 세로 약 520px, 가로 약 256px)를 사용해 보간을 억제합니다.
- **기존 내용 보존:** Blender 3D 건축 배경, 작품 이미지와 HTML 글씨, 작품 상세·등록·후기, 소등 AI·퓨즈·손전등·복구 엔진은 기존 기능을 그대로 둡니다.
- **폴백:** v5 이미지 20장 로드가 실패하면 검증된 v4, 그마저 실패하면 v3로 복귀합니다. 원본과 이전 이미지 삭제 없음.

## 실제 성능 및 품질 한계

- 새로운 스프라이트는 **384×512 셀에서 직접 추출**한 그림이므로 이전 228×408 원본을 키워 얻은 가짜 세부 묘사와 다릅니다. 다만 각 캐릭터가 셀 전체를 채우는 것은 아니며, 표정과 옷 디테일은 그 실제 그림 범위에 한정됩니다.
- `image-rendering: pixelated`는 픽셀 가장자리를 날카롭게 표시하지만, 한 픽셀보다 작은 미세한 세부 묘사를 새로 만들지는 못합니다.
- 변신 12프레임은 **픽셀 디더 전환**입니다. 완전한 수작업 애니메이션이나 Live2D 리깅이 아닙니다.
- 새 원화 시트는 원래 RGB 흰색 배경이어서, 셀별 외부에 연결된 밝은 배경 영역을 제거해 투명화했습니다. 검은 머리·옷을 색상으로 지우지 않았으나 세밀한 가장자리 수동 감수는 추가로 개선할 수 있습니다.
- 실제 Android/iOS 실기기 및 4K 화면의 전체 FPS/배터리 실측은 자동 크롬 테스트와 별개입니다.

## 검사

`.github/workflows/curator-v5.yml`은 다음을 실행합니다.

1. 새 아트 4×2 시트 크기 및 알파 검사, 일반 4장+괴물 4장+변신 12장(총 20장) 생성
2. JS 구문 검사와 기존 소등 상태 머신 단위 테스트
3. Chromium 데스크톱 1440×900, 모바일 세로 390×844, 모바일 가로 844×390
4. 미술관 배경 보존, 작품 이미지 비도트화, 비서/괴물의 실제 이미지 로딩 및 픽셀 렌더링, 미세 회전 제거, 변신 프레임 전환, 소등 복귀, 모션 감소, 오류·스크롤 검사
5. 모두 통과한 경우에만 새 WebP 20장과 아트 감사 JSON을 작업 브랜치에 커밋

**배포 기준:** 자동 검사 성공 및 화면 검수 후 PR을 `main`에 병합하고 GitHub Pages 배포를 확인합니다.
