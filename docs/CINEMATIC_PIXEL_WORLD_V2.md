# 오이붕 월드 — Cinematic Pixel Art v2

## 목표

2D 횡스크롤로 친구들의 게임을 직접 탐험하고 소개받는 **오이붕 월드**의 시각적 완성도를 대폭 올린다. 전투, 유료 시스템, 별도 웹페이지, 강제 스토리를 추가하지 않고 **건물마다 다른 세계를 방문한다는 느낌**을 강화한다.

## 이번 비주얼 리뉴얼

| 변경 | 구현 |
|---|---|
| 오든링 성 | 생성된 독창적 고해상도 판타지 성채 원화를 투명 외곽으로 추출해 실제 월드 건물에 적용. 입구의 황금빛 나무/현관/석상/꽃밭/첨탑을 아트에 포함 |
| 비서 | 블랙 헤어·조끼·버건디 넥타이를 통일한 새 **4×2 / 8포즈** 스프라이트 아틀라스 적용. 대기, 옆모습, 4걸음 프레임, 작품 소개, 손 흔들기 |
| 각 게임 건물 | 기존 고밀도 절차형 벽돌·지붕·창문 위에 더 세밀한 실제 석재 질감 오버레이 및 고유 상징 조각: 콜로세움 월계관, 검격 도장 쌍검, 전략 본부 관측 시계, 고양이 저택 벚꽃/고양이 휘장, 일반 스튜디오/탑의 천문시계 |
| 하늘 | 부드러운 하늘 그라디언트와 작은 구름, 달/태양 테마 전환. 오든링 구역에서는 고화질 환상 도시/절벽 원화를 자연스럽게 페이드 |
| 원경 | 고해상도 산악/도시 전망과 2.5D 패럴랙스, 황혼 성벽, 빛나는 창문, 공중 궁전 |
| 전경 | 기름 램프, 불빛, 꽃나무, 소나무, 꽃잎, 바닥 석재 조각, 포털 주변 광채 |
| 모바일 | 원래의 화면 전체 게임과 조이스틱·버튼 구조 그대로 사용, 새 비주얼을 화면 크기에 맞춰 렌더링 |
| 성능 | 복잡한 기하학과 나무·램프·산맥은 오프스크린 캔버스 캐시로 재사용. 건물의 LRU 캐시 최대 10개 유지. PC/모바일 렌더링을 Chromium으로 검사 |

## 기술 선택

- `world-cinematic-art.js`: 원화 자산 7개를 **로컬 WebP 데이터 URI**로 묶음. 외부 CDN 없이 동일 출처에서 데이터 URI 이미지로 디코딩 가능
- `world-cinematic-fx.js`: 레이어별 하늘·산맥·등불·정원·출입문 조명 렌더러
- `world-hd-architecture.js`: 새로운 성채 일러스트를 건물 형태의 투명 Canvas에 래스터 캐시. 나머지 게임별 건물은 고유 절차형 아트 + 텍스처 + 문양으로 꾸밈
- `oibung-world.js`: 8포즈 안내 비서 스프라이트 애니메이션, 새 레이어 통합, 기존 입장·워프·키보드·모바일 조작 보존
- `index.html`: 순서 의존적인 아트/FX/월드 스크립트 로드

**중요:** 새 성채와 비서 원화는 기존 대화의 이미지 생성 결과에서 나온 AI 보조 원화다. 이 코드 변경으로 모든 건물을 개별 수작업 3D 모델이나 완전 수작업 반실사 픽셀 일러스트로 교체했다고 주장하지 않는다. 오든링에는 고해상도 일러스트, 다른 게임 테마에는 절차형 픽셀그래픽과 실제 재질 질감을 적용한 것이다.

## 원래 기능 유지

- OIBUNG_CATALOG의 게임 수집과 Supabase 공유/리뷰 원본 데이터를 수정하지 않음
- 게임별 건물 이름표, 입구 충돌/선택, E 입장, URL/스크린샷/후기/수정
- 전체화면 게임 및 PC·모바일 터치 조작/등록 UI 보존
- 이미지 로딩이 느리거나 실패한 환경에서는 기존 인게임 비서와 코드로 그린 성채가 fallback
- 기존의 고밀도 Canvas 캐시와 플레이어 알파 판정 유지

## 자동 테스트

`tests/world-cinematic.cjs`는 실제 Chromium 브라우저 PC 1440×900, 세로 휴대전화 390×844, 가로 휴대전화 844×390에서 다음 항목 확인.

- 생성된 신규 WebP 아트가 전부 로드되는지, 오든링 성은 삽화형 Canvas인지
- 씬의 색상 다양성이 원래 단색 평면 도트에 비해 충분히 높은지
- 기존 게임 상세 입장·메뉴·전체 목록·후기가 계속 동작하는지
- 퍼리 게임을 테스트 메모리에서 추가하여 고양이 저택이 생성되는지
- 화면 전체 꽉 채움, 가로/세로 스크롤 없음, JavaScript 오류 없음, 장시간 프레임 멈춤 없음
- 테스트 아티팩트에 각 테마 및 PC·모바일 스크린샷 저장

실제 iOS Safari·Android 물리 디바이스 및 실서버 Supabase 쓰기는 별도 검수 대상이다.
