# 오이붕 갤러리 — 도트 고화질화 및 소등 플레이 v2

## 구현 목표 및 범위

**낮에는 작품을 감상하고, 소등 후에는 같은 전시관을 탐험하며 괴물 비서를 피해 비상전원을 복구하는 하이브리드 전시관**으로 개선한다. Blender에서 사전 렌더한 전시관 배경, 작품 썸네일·상세, 게임 등록·수정·후기는 변경하지 않는다. 도트 이미지는 비서와 같은 인물에서 변형된 괴물에만 적용한다.

## 1. 캐릭터 이미지 품질

- 소스: 승인된 `assets/curator-v3/guide-atlas.webp` 및 `monster-atlas.webp` 두 파일. 원본 유지.
- 새 빌드: `tools/build_curator_v4.py`, 원본 **228 × 408px** 셀 → 출력 **288 × 512px**, 손실 없는 RGBA WebP.
- 정적인 인간 4포즈, 동일 인물 괴물 4포즈, **10단계 변신**을 생성. 총 18개 이미지.
- 32/48/64색으로 일괄 양자화하지 않고 원본 색을 유지한다. 정교한 눈·옷·머리카락을 불필요하게 삭제하지 않도록 대비·샤프닝을 절제한다.
- 웹에서 무작정 408px 그림을 900px 이상 키우던 화면 배치를 조정해, 새 512px 이미지를 가능한 1:1에 가깝게 표시한다.
- v4 로딩 실패 시 v3 원본, 이후 기존 픽셀 자산으로 폴백하는 로직을 유지한다.
- **정직한 한계:** 408px 원본을 고품질로 업스케일해도 손으로 새로 그린 512px급 픽셀 세부 묘사가 만들어지는 것은 아니다. 같은 형태의 원본을 유지하는 단계에서 할 수 있는 선명도 개선이다.

## 2. 변신 연출

- 경계 자세 → 준비된 10개 `morph-00.webp`~`morph-09.webp` → 소등/괴물 탐색으로 연결.
- 각 프레임 약 80ms, 시작 정지 320ms, 종료 지연 90ms.
- 프레임들은 변신 이전에 로드·검증한다. 이미지가 아직 로드되지 않아 일시적으로 캐릭터가 사라지는 문제를 줄인다.
- **취소 가능:** 페이지 숨김, 일반 관람 복귀 또는 전환 중단 시 예약 프레임을 취소한다.
- `prefers-reduced-motion`을 켜면 변신을 생략하고 곧바로 어두운 모드로 진입한다.
- **한계:** 이 연출은 원래 비서와 괴물 그림의 10단계 형태 합성 + 약한 글리치다. 관절 단위 리깅, 무제한 부드러운 골격 애니메이션은 아니다.

## 3. 소등 게임 방식

`gallery-blackout-rules.js`에 독립된 경량 상태 머신을 둔다. 실시간 3D·물리 엔진을 추가하지 않는다.

### 기본 조작

| 플레이어 행동 | 작동 |
|---|---|
| 회랑 이동 | 화살표 버튼·키보드 좌우 화살표·스와이프. 이동 시 소음과 경계도 변화 |
| 손전등 | 켜면 퓨즈가 보이지만 발각 위험이 올라감. 끄면 위험은 낮아짐 |
| 조용히 걷기 | 다음 회랑 이동의 소음 및 발각 위험 감소 |
| 숨기 | 괴물이 가까워 경고가 나타난 경우 액자 뒤로 숨고 손전등 끔 |
| 기다리기 | 숨어 있으면 발소리를 듣고 안전하게 다시 탐색. 숨지 않은 채 괴물과 마주 보고 기다리면 붙잡힐 수 있음 |
| 퓨즈 회수 | 해당 회랑에서 손전등을 켜고 퓨즈를 회수. 같은 퓨즈 중복 수령 없음 |
| 비상전원 복구 | 예비 퓨즈를 모두 모은 뒤, 전원실에서 **퓨즈 설치 → 차단기 올리기** 두 번 조작 |
| 잡힘/실패 | 재시도 또는 일반 관람으로 즉시 복귀. 갑툭튀·불필요한 섬광 없음 |

### 순찰 AI 및 공정성

- 기본적으로 **사용자 행동과 약 4.8초마다** 몬스터의 방 위치를 순차 변경한다.
- 손전등, 이동 소음, 천천히 걷는 여부에 따라 발견 위험이 변한다. 위험도가 높아지면 괴물이 플레이어 위치를 향해 순찰 방향을 조정한다.
- 괴물과 같은 회랑에 진입하면 먼저 경고·숨기기·이동 기회를 제공한다. 이후 잘못 기다리면 잡힌다.
- 손전등 켜기/끄기, 숨기/기다리기, 괴물의 위치를 규칙 엔진으로 처리한다. 모든 장면마다 무작위 즉사 공격 없음.
- 1~30개 회랑에서도 퓨즈 수 및 전원실/괴물 위치가 유효하게 배치되도록 테스트한다. 게임 수 증가 시 방 수가 자동으로 증가하는 기존 구조 유지.

## 4. 손전등 가시성과 모바일

- 같은 렌더 카메라를 가진 `-light.avif` 이미지를 손전등이 비추는 영역에만 부분 합성하여 밤에도 길과 액자 주변을 구별할 수 있도록 했다.
- 손전등 OFF일 때는 낮은 환경 조도만 남기고, 버튼·현황 UI는 읽을 수 있게 한다.
- 비서와 액자가 모바일 세로 화면에서 과하게 겹치지 않도록 배치 및 크기를 수정.
- `bk-hud`에는 퓨즈 획득 수, 소음 정도, 발각 위험, 손전등 상태를 짧게 표시. 화면 전체에 긴 조작 설명문이 나오지 않게 한다.

## 6. 남은 검증 및 다음 개선

- 실기기 iOS Safari/Android Chrome에서 성능·손전등 포인터·터치 스와이프 검사.
- 실제 사용자 등록/수정/후기/스크린샷 업로드 회귀 테스트. 테스트 중 실제 사용자 데이터 변경 금지.
- 게임 플레이 중의 카메라 편의성 및 배경의 품질은 별도 작업 대상.
- 전용 손그림 애니메이션으로 변신 프레임을 더 세밀하게 제작하고, 괴물의 팔/머리 움직임 개별화.
- 저사양 휴대폰에서 최초 자산 로드 시간과 메모리 측정 후 필요하면 낮 이미지 우선 로드·야간 자산 비동기 프리로드로 개선.

**배포 정책:** 자동 QA와 스크린샷 검수를 통과한 뒤에만 PR을 `main`으로 병합하고 GitHub Pages 배포를 확인한다.
